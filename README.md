| Project | Description | Libraries |

| [Optimizing Energy Consumption during Steel Processing](final_project.ipynb) | The "Steel Bird" metallurgical plant aims to reduce electricity costs during steel processing in the ladle. **The project goal** is to develop a model that predicts the final steel temperature based on technological cycle parameters: arc heating, bulk material feeding, and gas purging. The model is designed to simulate the process and find optimal heating modes. <br><br> **Key stages:** preprocessing, feature engineering, modeling, analysis. <br><br>**Results:** The best LightGBM model achieved an MAE of 5.95 on the test set, meeting the target threshold of 6.0. The coefficient of determination $R^2$ was 0.39, confirming the model's adequacy compared to a constant prediction (DummyRegressor MAE: 7.43). | Pandas, NumPy, Scikit-learn, LightGBM, SHAP, Seaborn, Matplotlib |
| [Determining Customer Age from Photos](Computer_vision.ipynb) | This project was developed for the "Khleb-Sol" supermarket chain to analyze customer photos in the checkout area. This allows for personalized recommendations and helps monitor the sale of age-restricted goods. The model was trained on a dataset of images with age labels and achieved an MAE of 6.3 on the test set. | Pandas, TensorFlow, Seaborn, Matplotlib, Keras, ResNet50 |
| [Toxic Comments Classification](ML_for_texts.ipynb) | The project was developed for the "Wikishop" online store to automatically detect toxic comments and send them for moderation. <br><br>**Main task** — train a model to classify comments into positive and negative with a target F1 metric of at least 0.75. <br><br>**Work highlights:** Logistic Regression and CatBoost were investigated using comment embeddings obtained via the pre-trained 'unitary/toxic-bert' model. <br><br>**Results:** Both approaches exceeded the target threshold, with CatBoost showing the best result (F1-score 0.92 on the test set). | Pandas, NumPy, Torch, Transformers, NLTK, Scikit-learn, CatBoost |
| [Predicting Taxi Orders](time_series.ipynb) | The "Chyotenkoye Taxi" company collected historical data on taxi orders at airports. The goal of the project is to build a model that predicts the number of taxi orders for the next hour to attract more drivers during peak load periods. <br><br>**Main tasks:** <br> - Load data and perform resampling by one hour. <br> - Analyze time series. <br> - Train Linear Regression, Decision Tree Regressor, CatBoost, LightGBM, and Random Forest models with various hyperparameters. <br> - Conduct final testing and draw conclusions. | Pandas, NumPy, Seaborn, Matplotlib, Scipy, Sklearn, LightGBM, CatBoost |
| [Predicting Used Car Market Prices](gradient_boosting_.ipynb) | A used car sales service is developing an app for quick market price estimation based on historical data, including car specifications, configurations, and prices. The goal is to build a machine learning model for accurate car price prediction with fast prediction and training times. <br><br>**Methods:** Development and evaluation of several ML models for price prediction, including LightGBM, RandomForestRegressor and linear regression. Models were evaluated based on prediction accuracy (RMSE), training time, and prediction speed. <br><br>**Main tasks:** <br> - Data preprocessing: handling missing values, outliers, and non-informative features. <br> - Feature engineering: creating a new feature for car age and removing irrelevant features. <br> - Model training: training and tuning various models using appropriate feature encodings. <br> - Model evaluation: analysis of RMSE, training time, and prediction speed for each model. <br> - Model selection: recommending the model with the best performance according to business requirements. | Matplotlib, Numpy, Pandas, Seaborn, LightGBM, CatBoost, Sklearn |
| [Determining the Profitable Region for Oil Well Drilling](ML_in_business.ipynb) | The "GlavRosGosNeft" extraction company collects data on oil wells in three regions, including oil characteristics and reserves. **The goal of the project** is to build a model for reserve prediction and identify the region with the maximum total profit. <br><br>**Main tasks:** <br>- Data loading and analysis: checking for missing values, duplicates, and anomalies. <br>- Data preparation: separating target and non-target features, indexing. <br>- Model training: building a linear regression and evaluating its quality (RMSE). <br>- Profit and risk analysis: calculating financial indicators, applying Bootstrap. <br>- Determining the optimal region based on economic metrics and loss probability. | Pandas, NumPy, Sklearn, Matplotlib, Seaborn, Scipy |
| [Optimizing Business Decision-Making in HR Management](hr_decisions_business_oprimization_ml.ipynb) | HR department analysts help the business optimize personnel management: the business provides data, and analysts suggest solutions to prevent financial losses and employee turnover. <br><br>**Methods:** Building a model to predict employee satisfaction and a model to predict employee turnover. <br><br>**Main tasks:** Using machine learning to improve decision-making based on data-driven forecasts. | Matplotlib, Numpy, Pandas, Seaborn, Shap, Phik, Scipy, Sklearn |
| [Predicting Decreased Customer Activity](segmentation_supervised_learning.ipynb) | This project was developed for the "One Click" company to identify customers prone to a decrease in purchasing activity to create personalized offers. <br><br>**Main tasks:** <br>- Data collection and preprocessing from multiple tables (addressing multicollinearity, encoding categorical features). <br>- Finding the best model via Pipeline (comparing SVC, LogisticRegression, KNN, DecisionTree) using Optuna for hyperparameter tuning and cross-validation.<br>- Feature importance analysis (Permutation Importance) and model interpretation using SHAP.<br><br>**Results**: The best model — SVC (Linear) with MinMaxScaler reached a ROC-AUC of ~0.90. A "risk zone" customer segment was identified, along with key factors for the decline in activity. | Pandas, NumPy, Sklearn, Matplotlib, Seaborn, SHAP, Optuna |
| [Machine Learning for Dairy Farm Optimization](linear_models_in_machine_learning.ipynb) | This project develops machine learning models to optimize cow selection for the "Volny Lug" dairy farm to ensure stable milk production and compliance with taste quality standards. Two models predict milk yield and evaluate its taste characteristics. <br><br>**Methods:** Data preprocessing, exploratory data analysis, correlation analysis, regression and classification modeling. | Matplotlib, Numpy, Pandas, Seaborn, Phik, Scipy, Sklearn |
| [Statistical Analysis of Video Game Success](statistical_analysis_and_probability_theory_of_games.ipynb) | This project analyzes historical data on game sales, ratings, and genres to identify factors influencing the success of games. The findings will help the "Streamchik" company forecast successful games and plan marketing for 2017. The goal is to determine key success factors, including platform, genre, and ratings. <br><br>**Main tasks:** Data analysis and preprocessing, sales analysis by platform and genre, user preferences in different regions, hypothesis testing, and marketing recommendations for 2017. <br><br>**Methods:** Data analysis, regression, and hypothesis testing. | Pandas, NumPy, Seaborn, Matplotlib, SciPy |
